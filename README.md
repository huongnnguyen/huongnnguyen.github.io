# 🌱 huongnnguyen.github.io

My little portfolio, styled like a cozy farming sim: a tool belt for skills, a garden for contributions, and crops for projects.

**Live:** https://huongnnguyen.github.io

## What's inside

- **Profile card** with name, class progress bar, and a quick "Message me" button
- **Tool belt** of skills (press `1` to `8` or click a slot)
- **My little garden**, a contribution-style grid with hover readouts
- **Crops** for projects: [`corral`](https://github.com/huongnnguyen/corral) and [`Purrse`](https://github.com/huongnnguyen/Purrse)
- **Greenhouse** for coursework that lives off GitHub (PintOS, ARM emulator, ARG horror game)

## Run it locally

It's a single self-contained `index.html`. React and the fonts are bundled in, so there is nothing to install.

```
open index.html
```

## Deploy

Push `index.html` to the root of the `main` branch, then enable **Settings → Pages → Deploy from a branch → main / (root)**.

## Built with

React (bundled), Figtree, JetBrains Mono, and Pixelify Sans.
